Compute device

        
The server picks the fastest device automatically: NVIDIA GPU (CUDA) → Apple Silicon GPU (MPS) → CPU. Switching reloads the model (a few seconds to a minute).

        

          
          
        

        
Speed

        
Real-time factor (RTF) = seconds of computing per second of speech; below 1.0 is faster than real time. Measured on an RTX 3060 (12 GB) without torch.compile: RTF ≈ 1.7. Faster GPUs, fewer diffusion steps or --optimize (torch.compile, CUDA only) lower it; Apple Silicon and CPU are slower. Your own average is shown in the Engine table.
